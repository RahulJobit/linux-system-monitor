## 📊 Linux System Monitoring Tool

A lightweight **Linux system monitoring tool written in Bash** that provides real-time system statistics such as CPU usage, memory usage, disk usage, running processes, and network information.

This tool is designed for **system administrators, DevOps engineers, and developers** who want quick insights into system performance from the terminal.

---

## 🚀 Features

* CPU usage monitoring
* Memory usage statistics
* Disk usage information
* Running processes list
* Network activity monitoring
* Lightweight and fast
* Works on most Linux distributions

---

## 🖥️ Example Output

```
===== SYSTEM MONITOR =====

CPU Usage:        32%
Memory Usage:     4.1GB / 8GB
Disk Usage:       120GB / 256GB
Active Processes: 213
Network Status:   Connected
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/RahulJobit/linux-system-monitor.git
```

Navigate to the folder:

```bash
cd linux-system-monitor
```

Make the script executable:

```bash
chmod +x monitor.sh
```

Run the script:

```bash
./monitor.sh
```
